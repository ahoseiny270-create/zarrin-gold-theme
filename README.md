# زرین | قالب فروشگاه طلا ✨

قالب **فروشگاهی وردپرس** برای طلافروشی و جواهرفروشی — کاملاً راست‌چین و فارسی، سازگار با ووکامرس، دارای تیکر قیمت لحظه‌ای طلا و سکه و **راه‌اندازی دمو با یک کلیک**.

> 🆕 **نسخه ۱.۳.۰:** چهار دمو با یک نصب — از «نمایش ← سفارشی‌سازی ← ظاهر سایت» پوسته رنگ را عوض کنید.

---

## 🎨 چهار دمو، یک قالب

| دمو | پوسته رنگ | حال‌وهوا |
|-----|-----------|----------|
| ۱ | **زرین — تیره طلایی** (پیش‌فرض) | تیره، طلای کلاسیک، حس بازار طلا |
| ۲ | **زرین روشن — سفید-عاجی** | روشن و خوانا، کلاسیک و آرام |
| ۳ | **زرین زمرد — زمرد تیره** | زمرد سیاه‌قلم + طلای شامپاینی + مرمر عاجی |
| ۴ | **زرین کاکائو — شکلاتی/کاراملی** | اسپرسو + کاراملی + کرم، گرم و دنج |

با تغییر پوسته:
- فایل استایل مربوطه بارگذاری می‌شود (`style.css` یا `assets/css/skin-*.css`)
- تصاویر نمونه هیرو، درباره ما و محصولات از پوشه همان دمو خوانده می‌شود
- کلاس `zarrin-skin-<نام>` به تگ `body` اضافه می‌شود

متن‌ها و تصاویری که خودتان در سفارشی‌سازی تغییر داده باشید، دست‌نخورده می‌مانند.

## ✨ قابلیت‌ها

- **صفحه اصلی اختصاصی**: هیرو، تیکر قیمت، مزیت‌ها، محصولات ویژه، درباره ما، بنر تماس، وبلاگ
- **قیمت لحظه‌ای طلا و سکه**: دریافت خودکار از بازار (tgju.org)، کش سمت سرور، آخرین قیمت معتبر تا ۲۴ ساعت، نشانگر درصد تغییر سبز/قرمز، به‌روزرسانی آجاکسی هر ۹۰ ثانیه
- **ووکامرس**: استایل اختصاصی فروشگاه، محصولات ویژه، شمارنده سبد خرید با آجاکس، واحد پول تومان
- **راه‌اندازی دمو با یک کلیک**: ساخت برگه‌ها، منوها، نوشته‌ها، محصولات و تنظیمات — متناسب با پوسته فعال
- **فونت وزیرمتن متغیر** به‌صورت لوکال (بدون CDN)
- **پنل تنظیمات** کامل در سفارشی‌سازی + دو جایگاه منو (اصلی و فوتر)
- دسترس‌پذیری: پرش به محتوا، `aria` مناسب، احترام به `prefers-reduced-motion`

## 🚀 نصب

1. فایل `zarrin-gold-theme-1.3.0.zip` را از بخش Releases دانلود کنید.
2. در پیشخوان: **نمایش ← پوسته‌ها ← افزودن پوسته ← بارگذاری پوسته** و انتخاب فایل زیپ.
3. پوسته را فعال کنید، دکمه **«راه‌اندازی دمو با یک کلیک»** را بزنید و پوسته رنگ دلخواه را انتخاب کنید.

نیازمندی: وردپرس ۶ به بالا — PHP 7.4 به بالا — ووکامرس (برای بخش فروشگاه)

## 📁 ساختار

```
style.css                  استایل دموی ۱ (تیره طلایی)
assets/css/skin-light.css  پوسته دموی ۲
assets/css/skin-emerald.css پوسته دموی ۳
assets/css/skin-choco.css  پوسته دموی ۴
assets/img/                تصاویر نمونه دموی ۱
assets/img/skins/          تصاویر نمونه هر پوسته
assets/fonts/              فونت وزیرمتن متغیر (لوکال)
inc/demo-import.php        راه‌اندازی دمو با یک کلیک
functions.php              توابع قالب + پوسته‌های رنگ + قیمت لحظه‌ای
front-page.php             صفحه اصلی ویژه
```
